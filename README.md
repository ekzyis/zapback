# zapback

## New game

1. Pay lightning invoice to fund pool
2. Generate link to send to friend
3. Friend also pays into pool
4. Now they pay a few sats into the pool each day until someone forgets and loses
5. Enter lightning address (future: bolt12)

(future: p2p zaps as "pokes" which can reuse wallet notifications)

## Load game

1. Enter link
2. See state of game:
    - who has to pay next
    - how much time is left
    - lightning invoice
